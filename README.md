# OhRats UI

Shared visual language for OhRats Technologies. Core styles live in the fingerprinted `ohrats.css`, including the canonical public header and footer; optional cross-product components such as the copy field and semantic state colors are published as their own fingerprinted stylesheets.

Consumers use content-fingerprinted `/assets/*` URLs directly. Shared assets are immutable and do not have mutable aliases or redirecting compatibility URLs.
