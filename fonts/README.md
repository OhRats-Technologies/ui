# MesloLGS Nerd Font Mono

`MesloLGSNerdFontMono-Regular.woff2` is the unsubsetted Regular Mono face from Nerd Fonts MesloLGS, pinned to Nerd Fonts v3.4.0 and converted from the upstream TTF to WOFF2 without removing glyphs.

Upstream source:
`patched-fonts/Meslo/S/Regular/MesloLGSNerdFontMono-Regular.ttf`
